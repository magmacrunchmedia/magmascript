magmascript

A Python-inspired mini language with a tree-walk interpreter. Write .mgs scripts, run them in your browser.

Install

pip:

pip install magmascript

Features

  • Variables, functions, arrow functions
  • Lists, dicts, list comprehensions
  • String interpolation (f-strings)
  • Classes with methods
  • Control flow: if/else, for, while
  • Slicing: [1:3], [::-1]
  • Error handling: try/haunter, throw fire toad
